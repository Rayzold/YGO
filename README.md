# YGO card database (generated)

Rebuilt nightly by `.github/workflows/build-deploy.yml` on `main`. Do not edit.

- `cards.json`  every OCG/TCG card: names in all languages, English text, mechanic tags,
  TCG/OCG legality, current and upcoming limits (0 Forbidden, 1 Limited, 2 Semi-Limited, 3 Unlimited)
- `prints.json` English (TCG) and Japanese (OCG) prints, one row per rarity
- `meta.json`   build time, banlist dates, counts

Sources: YAML Yugi (cards) and YAML Yugi Limit Regulations (Konami banlists).
Card names and text are © KONAMI.
